# 备份与安全

[English](./backup-and-safety.md)

> 重要存档请自行另存一份。应用内历史便于恢复，不能完全替代外部备份。

## 备份放哪

默认在存档目录旁按槽位存放版本化副本：

`nier-save-editor-backup/<槽位>/`

例如存档在 `...\NieR_Automata\`，则 `SlotData_0.dat` 的备份在 `...\NieR_Automata\nier-save-editor-backup\SlotData_0\`。

可在**设置**中指定**自定义备份根目录**。需要打开资源管理器时，用设置或存档页的**打开备份文件夹**。

## 会快照什么

| 操作 | 行为 |
| --- | --- |
| 手动备份 | 复制**磁盘上当前**槽位文件；编辑器里**未保存**的修改不会进备份。 |
| 保存 / 导入 / 还原之前 | 对磁盘目标自动做安全快照，再执行托管写入。 |

备份失败、冲突、提交或校验失败时**不会**报成功。写入走同目录安全替换，并回读校验（大小 + SHA-256）。

## 还原与替换

- **还原**备份到选中槽位：先看方向预览，确认后再写。
- 用外部 PC `.dat` **替换**槽位：同样先预览再确认。

还原/替换后若界面仍旧，请重新扫描或重新加载。

## 实用建议

1. 关键槽位至少在游戏目录外留一份（网盘、U 盘、压缩包等）。
2. 保存/还原前尽量退出游戏，避免游戏同时写同一槽位。
3. 优先还原你能认出来的备份（时间 + 摘要），不要盲选。
4. 不要分享或提交真实 `.dat`——可能含 Steam 进度与标识信息。
